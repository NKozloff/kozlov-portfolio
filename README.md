ПОЛНЫЙ САЙТ С ОРИГИНАЛЬНЫМИ ШРИФТАМИ

Это полный архив портфолио (главная, Core, Echo, изображения, видео и шрифты).

Оригинальные шрифты восстановлены в папке assets/:
- assets/singel-bold.ttf
- assets/singel-semibold.ttf
- assets/arial-cyrillic.ttf
- assets/arial-cyrillic-bold.ttf
- assets/arial-regular.ttf

В styles.css используются только локальные файлы шрифтов, без внешней загрузки.
Заголовки, размеры и типографические стили не изменены. Новый раздел «Прокси» в core/index.html сохранён.

Распакуйте архив и загрузите ВСЁ его содержимое в корень репозитория NKozloff/kozlov-portfolio.
Проверяйте наличие 5 TTF-файлов в assets/ после загрузки.

Важно: заменяйте файлы, но не удаляйте другие данные репозитория, если они есть.
